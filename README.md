📌 Project Overview

This project is an embedded systems prototype built using an Arduino Uno and an I2C 1602 LCD Display. It features a physical Toggle Switch to control a continuous scrolling marquee message ("Selamat datang ke Politeknik Ibrahim Sultan"), accompanied by Red and Green LED status indicators that reflect the system's operational state in real-time.


🛠️ Hardware Requirements
- Arduino Uno (Microcontroller)
- LCD 1602 Display with I2C Module (16 columns, 2 rows)
- Toggle Switch (Rocker Switch / Slide Switch)
- Green LED (Running state indicator)
- Red LED (Stopped state indicator)
- Resistors (220Ω or 330Ω for LEDs)
- Breadboard (400-hole or 830-hole) & Jumper Wires (Male-to-Male and Female-to-Male)


🚀 How to Run
1. Open Arduino IDE.
2. Install the LiquidCrystal_I2C library via the Library Manager.
3. Connect your Arduino Uno to your PC via USB.
4. Select the correct Board and COM Port.
5. Paste the code, compile, and upload!
